# 质量 · 原创 · 合规核查清单（发布前逐项确认）

## A. 叙事与策划
- [ ] 五幕结构齐全：钩子 → 共鸣 → 高潮 → 回收 → 行动（科普段"知道做什么"）
- [ ] 主题积极且可检验：不否定努力，只纠偏错误信念
- [ ] 一句话能说清全片
- [ ] 台词与字幕零错字、逐句一致；特殊声台词**顺序念，不叠声**

## B. 视觉
- [ ] 全片统一风格前缀；角色各幕发型/服装/识别符号一致
- [ ] 色彩情绪曲线：冷（1–3 幕）→ 暖（4–5 幕）
- [ ] 无网络/第三方素材、无品牌标识、无混入文字/水印

## C. 动画（反 PPT 感）
- [ ] 每镜有角色表演（呼吸/微动），静止图停留 ≤6s
- [ ] 相机首尾缩放差 ≥0.06，且有横移/手持变化，不全是居中推
- [ ] 预备 → 动作 → 缓冲节拍；幅度宁小勿抽搐
- [ ] 镜间交叉溶解 + 镜内表情过渡（src 变体），非硬切轮播
- [ ] 信息图卡有图形反馈音 + 字幕呼吸动效

## D. 音频
- [ ] 三段配乐情绪与五幕对齐；纯器乐无歌词；首淡入片尾淡出
- [ ] 四类音色互不相同；主角与虚拟自我"同源不同调"
- [ ] 配音排程重叠数 = 0；`atempo` 在 `adelay` 之前
- [ ] 响度 −16 LUFS / TP −1.5dBTP（两遍 loudnorm）；科普段配乐避让旁白

## E. 工程与复现
- [ ] scene.py 单一事实源；文档（逐镜动画分镜表）由脚本自动生成
- [ ] 支持单镜重渲（--shots）与只重装（--no-render）
- [ ] 可编辑 .mlt 工程存在且已验证可打开
- [ ] 全部提示词已归档（轮次/目的/参数/产出）

## F. 发布与合规
- [ ] 成片命名规范（如"班级-姓名-作品名称.mp4"）、时长/体积符合平台要求
- [ ] 片头片名卡；片尾电影式滚动字幕（理念/工具/祝福/版权）+ 感谢观看定格
- [ ] 生成模型许可证允许商用（如 Apache-2.0），模型本地推理
- [ ] 宣传物料：主海报、技术栈海报、文案包（多平台多长度）、预告片 ≤60s
