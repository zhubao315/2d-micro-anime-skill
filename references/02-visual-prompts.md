# ② 视觉：多轮一致性提示词（Prompts）方法论

> 验收门：风格前缀统一、角色一致性符号明确、每轮提示词落盘归档、负面提示词全轮通用、
> 生成后人工核对清单全过。

## 1. 先定风格，再出图

全片统一画风（示例：**轻薄半赛璐 / 淡彩赛璐 Soft Cel + Paper Texture**，校园题材适配度最高）：

- 弱化黑轮廓线，改用**彩色线稿**（深蓝灰 / 暖褐描线）；
- 赛璐大块平涂阴影上，**叠加极淡水彩晕染 + 纸张颗粒纹理**；
- 体积光朦胧，不做强光束，偏向漫射空气光；阴影内带微弱环境色晕染；
- 观感像水彩绘本动画：温柔、文艺、故事感强。

**统一风格前缀**（每条提示词都内嵌，跨工具迁移直接复用）：

```text
轻薄半赛璐淡彩动漫风格：弱化黑色轮廓线、改用深蓝灰与暖褐彩色线稿，
赛璐平涂阴影上叠加极淡水彩晕染与纸张颗粒纹理，柔和漫射空气光，
朦胧体积光不做强光束，阴影内带微弱环境色晕染，无厚涂笔触，水彩绘本质感
```

## 2. 角色一致性：把"身份符号"写进定义

角色统一定义为可复用的短句（跨轮复用），并且要有**原创识别符号**：
示例——`林一/A B≈15岁男高中生，黑色短碎发，深蓝水手领校服`，
符号：`左胸校徽为空白凹槽`（现实自我）↔ `发光满环`（理想自我）。

三角色一致性表（一图定三人）：三视图并排、白色背景、比例一致、标注留白；
"同源不同调"设计（现实自我与理想自我同脸同身高，只靠发光描边/表情/校服反光区分）。

## 3. 多轮提示词法（示例 6 轮，满足 ≥5 轮）

| 轮次 | 位置 | 目的 | 产出 |
|---|---|---|---|
| 1 | 开头 | 锁定画风 + 色彩基准：片头背景 + 主角主形象 | 开场背景 / 主形象 |
| 2 | 中间① | 场景世界观：4 个主要场景（统一透视与色温） | 场景图 ×4 |
| 3 | 中间② | 三名角色一致性表 + 关键对照符号 | 三人设定表 |
| 4 | 中间③ | 一、二幕高潮分镜（冷现实 vs 亮虚拟对照） | 高潮镜头图 |
| 5 | 中间④ | 抽象理论视觉化 + 暖色反转（情绪回收） | 理论/治愈镜头图 |
| 6 | 最后 | 情绪落点（真实笑容）+ 片尾定格 + 基调校验 | 落点/定格图 |

每轮提示词都要**落盘归档**：目的、完整提示词、技术参数（分辨率/步数/CFG/种子）、产出路径。
抽象概念（如"理想中的自己"）转成视觉语言：像素光点聚成、青蓝柔光描边、屏幕光带分屏、
过曝高亮带裂纹的镜面、暖色光点碎裂飘落——**用明暗与色温讲情绪**。

## 5. 跨工具迁移

同一套提示词迁移到 Midjourney / SD / 即梦 / 可灵，只需替换**风格后缀**：

```text
(masterpiece, best quality, soft semi-cel anime, colored lineart instead of black,
light watercolor wash over cel shading, paper grain texture, diffused ambient light,
hazy soft volumetric light, subtle ambient color bleed in shadows, no thick impasto,
hand-drawn picture-book feel, chinese high school setting) --ar 16:9
```

## 6. 生成后人工核对

- [ ] 无任何网络/第三方素材或品牌标识

- [ ] 色彩曲线：冷蓝（1–3 幕）→ 暖橙（4–5 幕）
- [ ] 画风全片统一（同一风格前缀）
- [ ] 主题积极、无文字/水印混入
