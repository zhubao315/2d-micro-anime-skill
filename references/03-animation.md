# ③ 动画：自研 2D 网格形变引擎（角色表演 + 逐镜相机）

> 验收门：每镜有表演与相机运动、逐帧渲染可调试单镜、无 PPT 感。
> 引擎代码见 `engine/warp.py`（形变器 + 位移场）与 `engine/render.py`（一次重采样合成）。

## 1. 原理（为什么不是"图片轮播"）

把插画当作一张**可形变的皮肤**：

- 每个 `Deformer`：支点 `pivot`、作用半径 `sigma`（高斯权重）、变换类型；
  - `translate`：平移（抬手）；
  - `affine`：绕支点旋转 + 缩放 + 平移（转头、摆身）；
  - `squash`：竖/横压缩（呼吸、眨眼挤压）；
  - `bend`：越靠近支点上方横移越多（转身、侧倾、头发/衣摆摆动）。
- 多个形变器按**高斯权重**融合为全图位移场 → 双线性重采样 →
  "角色在动、背景基本不动"的一帧。
- **性能**：权重图与网格只按镜头算一次，每帧只更新参数、按包围盒重采样（单帧几十毫秒）。

相机（`affine` 逆变换）负责"镜头在动"：首尾缩放 z0→z1、绕焦点旋转、整幅占比横移、
手持晃动包络（`shake=[(t, 幅度), ...]`）。相机与形变**合成成一次重采样**（速度的关键）。

## 2. 逐镜导演表（rigs）字段

```python
DIR = {
  "s03": dict(focal=(0.36, 0.52),        # 焦点首尾（归一化 0..1）
              cam=(1.02, 1.12, -0.02, 0),  # z0, z1, panx, pany（整幅占比）
              perf="phone",                # 表演预设
              arm=(0.40, 0.60),            # 手锚点
              head=(0.55, 0.38),           # 头锚点
              beat=0.5,                    # 预备-动作-缓冲节拍
              shake=[(0.0, 2.8), ...]),    # 手持晃动包络（可选）
}
```

表演预设（`update(t)` 按归一化进度更新参数）：`idle`（呼吸）、`sit`、`write`（手臂微动 +
笔尖节奏）、`phone`、`lookup`（预备-抬头-停）、`reach`（伸手带方向向量）、`cover`（捂耳 +
头部内缩）、`smile`（`smile_fade`：笑容渐隐，节拍控制）、`run`、`abstract`（理论段极缓呼吸）、
`still`（纯相机镜）。总增益 S≈2.1 控制幅度；幅度宁可略小、不可抽搐。

## 3. 渲染流水线（`anim_build.py` 的职责）

```text
scene.SHOTS 逐镜 ─▶ rigs 装配形变器+相机 ─▶ render 逐帧（25fps）
 ─▶ ffmpeg 逐段编码 clips/*.mp4 ─▶ 逐段手写交叉溶解 0.5s（镜内再做一次表情过渡）
 ─▶ 叠加缓慢漂移柔光 + 受亮度约束的纸纹颗粒 ─▶ 烧入 ASS 呼吸字幕（淡入上浮+关键词渐暖）
 ─▶ 混入配乐 ─▶ H.264/AAC（faststart）成片
```

- 卡片镜（`src` 以 `#` 开头）：片头字幕卡 `make_title_card()`、片尾滚动字幕 `credits_clip()`
  （黑底上滚：片名/心理学理念/制作工具/祝福/版权）、末帧"感谢观看"定格 `make_end_card()`。
- 信息图卡（科普段三步）由 `make_info_card()` 程序化合成——**图卡也是脚本生成，不是手绘**。
- **调试粒度必须保留**：`--shots s03 s04` 只重渲指定镜；`--no-render` 只重装不重渲。

## 4. 与旧版（Ken Burns）的关系

保留 v1"整图推拉"脚本作对照/兜底，但成片动画由网格形变引擎产出。
升级路径：先每镜给 `idle` 呼吸 + 首尾缩放 ≥0.06，再逐步加锚点微动与 shake。

## 5. 逐镜动画分镜表（给人看的文档）

由 `anim_manifest.py` 从 `scene.py` + `rigs.py` 自动生成 markdown：
镜号 / 时长 / 相机 / 表演 / 光效 / 字幕动效 / 验收要点。**改镜头只改 scene.py，文档重跑即新。**
