# ⑥ 宣传：主视觉 · 文案 · 预告片 · 网站 · 原创合规

> 验收门：主视觉与全片同风格、文案可直接投多平台、预告片 ≤60s、宣传网站自包含、
> 原创合规自查全过。

## 1. 主视觉（与成片同一套提示词/模型生成）

- **主海报（竖版）**：主角真实笑容 + 暖橙光，留白叠片名与副标题；
- **技术栈海报**：全部工具/模型/版本/用途清单（程序化生成 `tools_poster.py`，投稿"动画制作软件名称"直接用）；
- **角色卡 / 九宫格 / 展架 / 公众号头图**：复用角色一致性表与场景图，统一裁切规范。

## 2. 文案包（多平台、多长度现成可用）

- 一句话钩子（例："他们都说我过得真好，可我开始怀疑：是不是自己不够好。"）；
- 简介 80 字 / 300 字 / 长文案三档；话题标签与平台适配（横竖屏、封面规范）；
- **投稿清单与合规核对**：类别、时长/体积上限、命名规范、设计要求逐项打勾。

## 3. 预告片（≤60s）

由脚本剪成：钩子镜头 ×3 + 情绪对比分屏 + 落点镜头 + 片名卡；
配乐用结尾段（暖）或开场段（冷→暖反转），字幕大、信息密度低。

## 4. 宣传网站（自包含单页）

原生 HTML/CSS/JS：Canvas 粒子、视差、滚动揭示；资产由 `site_build.py` 从项目目录抽取；
可直接挂 GitHub Pages；内嵌成片（配音版）与全项目文档入口。
本地预览：`python3 -m http.server 8791`。

## 5. 原创与合规（一句话自查）

> 角色、场景、剧情、台词、分镜、提示词均为**原创设计**；图像/配乐/配音由本地开源模型
> 依据本项目提示词生成；音效由脚本程序化合成；**不含任何网络下载、搜集或破解的第三方素材**。

核查清单（发布/投稿前逐项确认）：

- [ ] 主题积极、立意可检验（不否定努力，只纠偏错误信念）
- [ ] 主要角色含原创识别符号（便于查重比对）
- [ ] 成片时长/体积/命名符合目标平台要求
- [ ] 片尾滚动字幕含理念声明、工具声明与版权页
- [ ] 生成模型许可证允许使用（如 Apache-2.0），全模型**本地推理**（数据不出本机）
- [ ] 全部提示词已归档（可复现 = 可证明原创流程）
