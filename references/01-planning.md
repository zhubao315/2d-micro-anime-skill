# ① 策划：剧本 · 分镜 · 逐镜动画分镜

> 验收门：剧本五幕齐全、每镜有景别/时长/画面/声音/字幕、逐镜有运动与微动设计、
> 通过"反 PPT 审查"（见文末清单）。

## 1. 五幕结构公式（总长按配额分配，示例 180s）

| 幕 | 配额 | 叙事任务 | 观众获得 |
|---|---|---|---|
| 一 · 钩子 | 0:00–0:35 | 用具体场景立人设、埋悬念 | "这是我的日子" |
| 二 · 共鸣 | 0:35–1:15 | 让矛盾具体化（虚拟自我/内心声音登场） | "我也这样想" |
| 三 · 高潮 | 1:15–1:55 | 视觉化抽象冲突 + 一句说破痛点 | "被说中了" |
| 四 · 回收 | 1:55–2:20 | 不立刻变好，而是"接纳/换一种方式努力" | "原来可以这样做" |
| 五 · 行动 | 2:20–3:00 | 从故事自然过渡到原理 + 三步行动建议 | "看完知道做什么" |

要点：
- 前三幕"用故事说话"，第五幕"把工具交到观众手里"——科普段要清晰可信、**不作广告腔**。
- 主题必须可检验：不否定努力，只纠偏"必须先完美才配被喜欢"这类错误信念。
- 一句话能说清核心："你可以努力成为更好的自己，但不必先变得完美，才配得到认可。"
- 情绪曲线：色彩 冷蓝（1–3 幕）→ 暖橙（4–5 幕）；配乐 悬 → 冲突 → 释然。

## 2. 分镜表（DOC-A2）字段

每镜一行：`镜号 | 时间 | 景别 | 时长 | 画面（人物/动作/构图） | 声音（台词/BGM情绪/音效） | 字幕`。
示例：

```text
s07 | 0:24–0:29 | 中近景 | 6.0s | 洗手间隔间，林一低头，屏幕冷光，消沉变体 | 低频心跳铺底 | 旁白"是不是自己不够好"
```

## 3. 逐镜动画分镜（DOC-A3，决定"动起来"的质感）

在 DOC-A2 之上补四列：

- **运动**：相机首尾缩放(z0,z1) / 平移(整幅占比) / 是否手持晃动；
- **微动**：表演预设 idle / sit / write / hand / phone / lookup / reach / cover / smile / run
  + 头/手锚点坐标（归一化 0..1）+ 预备-动作-缓冲的节拍 beat；
- **光效**：镜面反光 / 暖色光点 / 纸纹颗粒 / 柔光漂移；
- **字幕动效**：淡入上浮 + 关键词渐暖（ASS 覆写呼吸动画）。

> 该表由 `anim_manifest.py` 从 `scene.py`+`rigs.py` **自动生成**，人只核对不手写。

## 4. 台词与配音台本

- 每句台词绑定 `镜号 + 镜内偏移`，不写绝对秒；绝对时间轴由脚本解析生成。
- 镜面声/多重回声类台词**顺序念，不叠声**（压迫感来自"依次逼近"而非混响叠加）。

## 5. 反 PPT 审查清单（策划阶段即要能回答）

- [ ] 每镜都有**角色表演**（至少一处微动），无静止图停留 >6s
- [ ] 相机首尾缩放差 ≥ 0.06（z=1.00→1.14 一类），且有横移/手持变化，不全是居中推
- [ ] 有"预备 → 动作 → 缓冲"节拍（beat），不是匀速
- [ ] 镜间用交叉溶解 + 镜内表情过渡（src2 变体图），不是硬切轮播
- [ ] 信息图卡（科普段）有图形反馈音 + 字幕呼吸动效
- [ ] 色彩/音乐情绪曲线与五幕对齐
